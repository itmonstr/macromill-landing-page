# Лендинг МакроМилл

Статичная версия лендинга MacroMill, опубликованная через GitHub Pages. Файлы сайта находятся в `site/`.

Публикация обновляется автоматически при каждом изменении ветки `main`.

Лендинг использует данные меню и тарифов из существующего собранного модуля
`site/assets/ration-Dutl8qkK.js`. Страница `site/checkout.html` сохраняет введённые
поля в сессии браузера и готовит письмо с заявкой менеджеру. Отправка письма
завершается самим клиентом в его почтовом приложении. Автоматического создания
заказа и оплаты пока нет; подтверждение даты также остаётся за менеджером.

Шрифт заголовков хранится в `site/fonts/Cygre-Medium.ttf`. Видео для первого
экрана и фотографии блюд находятся в `site/video/` и `site/img/`.
